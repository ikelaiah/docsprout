# Implementation Plan: v0.18.0 — Simple Configuration & Stable Customisation

## Overview

The final pre-1.0 simplification and contract-candidate release. Theme:

> Minimal CLI + obvious declarative configuration.

DocKit stays a few commands that perform operations; `layout.json`,
`dockit.json` and `versions.json` describe the site. No page-management or
section-management commands are added; nothing existing is removed.

## Baseline (inspected and verified)

- Working tree on `main`, clean, at merge commit `bb8a8f1` (Release v0.17.0),
  annotated tag `v0.17.0` on that commit.
- Suite: Pure Python stdlib unittest, 160 tests, all green locally.
- Own docs: `check` clean, `audit --strict` clean.
- Historical evidence inspected from immutable tags v0.1.0..v0.17.0: the
  schema-1 field families are stable (`project`, `theme`, `layout`, `banner`,
  `identity`, `homepage`, `navigation`, `home`, `unlisted`, `versions`).
  This evidence feeds the strict-field policy and the compatibility corpus.

## Architecture decisions

- **Strict fields, helpful diagnostics.** Reject unknown fields inside
  documented schema-1 objects for `dockit.json`, `layout.json` and
  `versions.json`, with a `Did you mean 'x.y'?` suggestion via
  `difflib.get_close_matches`. Every field family in the rejection set is
  one that has legitimately existed in a released tag (verified above), so
  valid historical schema-1 configurations keep loading.
- **`--dk-*` public token family.** Rename the generic first-class semantic
  tokens (`--bg`, `--surface`, `--text`, `--muted`, `--border`, `--code`,
  `--code-text`, `--raised`, `--focus-ring`, `--interactive`) to the
  namespaced `--dk-*` family. This is a documented pre-1.0 rename; no aliases
  are committed. Spacing/font/radius/control-height tokens stay internal
  implementation variables with no contract.
- **Custom CSS escape hatch.** `theme.custom_css` accepts only a non-empty
  repository-local `.css` path that exists and resolves inside the
  repository; it is copied deterministically to `assets/custom.css` and the
  stylesheet loads after DocKit's normal styles on every generated page,
  including nested and versioned builds. No CLI command, no network, no
  parser.
- **Route contract hardening.** Deterministic pre-build route-collision
  detection over exact and casefold-colliding routes (case-insensitive
  platforms are part of the supported surface). Existing route shapes are
  preserved.
- **Machine contracts versioned.** `search-index.json` becomes
  `{"schema_version": 1, "entries": [...]}`; audit JSON gains
  `"schema_version": 1`. Browser search code and tests updated in lockstep.
  `release.json` and build-output `versions.json` already carry schema
  versions.
- **`init` teaches, never mutates.** New guidance block communicates the
  mental model (Markdown, `layout.json`, `dockit.json`, `serve`) and shows
  inferred sections only when it created the layout.
- No new runtime dependencies; stdlib-only implementation.

## Failure policy

Bugs discovered during implementation get a focused regression test and the
smallest coherent fix. A requirement that would break valid historical
schema-1 configuration is investigated first; a real tradeoff is documented
and the smallest defensible pre-1.0 correction chosen. No gate is weakened
or skipped to land the release.

## Risks and mitigations

| Risk | Mitigation |
| --- | --- |
| Token rename breaks custom visual expectations | Documented pre-1.0 rename; new name family ships with contract tests; migration guide notes it |
| Strict fields reject an obscure historical field | Rejection set is built from the inspected v0.1.0–v0.17.0 field corpus; corpus test proves historical configs load |
| Search-index shape change breaks old embedded search | Search JS ships with the site; both updated in lockstep and regression-tested |
| Custom CSS breaks accessibility claims | DocKit owns inclusion mechanics only; docs state the author-responsibility boundary clearly |
| Route collision guard too strict | Only exact or casefold-equal published routes are rejected; shapes themselves are unchanged |
